# Profits Portfolio — Workspace Rules

## Project Context
This is a **Digital Product Designer portfolio** built with React + Vite + TailwindCSS.
The candidate specializes in **Enterprise B2B SaaS, Design Systems, and DesignOps**.

## Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** TailwindCSS
- **Routing:** HashRouter (SPA deployed to GitHub Pages)
- **Design Files:** Pencil (.pen) in `src/designs/`
- **Context Files:** Markdown prompts in `contexts/`

## Coding Standards
- Use functional components with hooks
- Follow existing naming conventions in `src/pages/` and `src/components/`
- Keep components focused and reusable
- Use TailwindCSS utility classes — no inline styles

## Content Standards
- Write all UI copy and case studies in **English**
- Use leadership verbs: architected, orchestrated, governed, scaled, established, drove
- Never invent metrics — extract them through targeted questions
- Every case study must include scale indicators: team size, components, products served

## Design Files
- `.pen` files are encrypted — use **only Pencil MCP tools** to read/write them
- Never use grep or view_file on `.pen` files


## Case Study Standards
- Never invent metrics — extract them through targeted questions first.
- Always include scale indicators: team size, number of components, products served, user base.
- Every case study must answer: "How did this scale across teams, products, or organizations?"
- Connect every design decision to a business KPI: efficiency gains, error reduction, cost savings, onboarding time.

## Voice
- Frame problems in terms of patterns, scale, and governance — never as isolated tasks.
- Use leadership verbs: architected, orchestrated, governed, scaled, established, drove, championed.
- No vague claims — every sentence must carry specific, provable meaning.

## Pressure-Test Before Delivering
- Before showing any case study draft, read it as a hiring manager at Atlassian, Datadog, or Figma.
- Flag anything that sounds junior, lacks proof of systems thinking, or could apply to any designer.

## Candidate Context
- Role target: Senior / Staff Digital Product Designer & Design Systems Owner
- Specialization: Enterprise B2B SaaS · Backoffice · Data-dense interfaces
- Key differentiators: Design Systems governance, DesignOps, AI-augmented pipelines, functional prototyping
