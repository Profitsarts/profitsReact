# Design System: Profits Portfolio 2026
**Project ID:** 10249604635266234764

## 1. Visual Theme & Atmosphere
The atmosphere is **Sophisticated, Authoritative, and Architecturally Sound**. It blends mid-century modern typographic elegance (Museo Slab) with cold, precise geometric gothic (Avant Garde). The interface feels like a high-end design atelier—clean, structured, and premium. It prioritizes clarity and rhythm, using a light off-white background with high-contrast slate-gray text and a single, high-energy magenta accent.

## 2. Color Palette & Roles
* **Dark Slate Gray (#323a45):** The primary structural color. Used for headings, borders, buttons, and high-importance UI elements. Conveys authority and precision.
* **Vibrant Magenta-Pink (#f61067):** The "Energy" accent. Used exclusively for hover states, active links, and focus boundaries. It breaks the monochromatic grid with a spark of creativity.
* **Soft Silver Slate (#64748b):** The secondary/neutral color. Used for muted text, labels (h6), and secondary context.
* **Studio White (#f8f8f8):** The canvas background. A very light off-white that feels warmer and more premium than pure white (#ffffff).

## 3. Typography Rules
The typography system uses a **Mixed-Aesthetic Strategy**:
* **The Voice (Museo Slab):** Used for all major headers (h1-h5). A robust slab-serif that feels both historic and contemporary.
* **The Structure (ITC Avant Garde Gothic):** Used for body copy, labels, and architectural details. A geometric sans-serif that is ultra-modern and clinical.
* **H6 Labels:** Allcaps, ultra-wide tracking (`tracking-widest`), and small font scale (`text-xs`). Used for metadata and category headers.
* **Paragraphs:** Base font size with generous line height (`leading-relaxed`) for maximum readability in long-form narratives.

## 4. Component Stylings
* **Buttons:** Rectangular with minimal rounding. Solid Dark Slate (#323a45) background, white text, uppercase, tracking-widest. Interaction: Background swops to Vibrant Magenta-Pink (#f61067) on hover.
* **Filter Pills:** Fully rounded (pill-shaped). Active state uses a Dark Slate background with white text. Inactive states are minimalist with soft gray text.
* **Cards/Containers:** Minimalist with focus on the content. Grid-based layout with uniform 24px gaps. Border-Y dividers are used to separate major sections.
* **Forms/Inputs:** Sharp-edged or very subtly rounded. Backgrounds match the Studio White (#f8f8f8) with a 1px neutral border. Focus state activates a Magenta-Pink border.

## 5. Layout Principles
* **Rhythmic Spacing:** Sections are separated by generous vertical whitespace (64px to 80px). 
* **Border Dividers:** Horizontal lines (#323a45) are used to frame section titles, creating a "leveled" structure.
* **Containment:** Content is strictly centered in a layout container with 24px side padding to preserve focus and professional margins.
