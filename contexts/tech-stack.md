# Tech Stack & Orchestration

## Core Environment
*   **Framework**: React.js 18+ (Vite-powered).
*   **Styling**: Tailwind CSS (Primary) + Vanilla CSS (Global overrides).
*   **Motion**: Framer Motion for interactive transitions and micro-animations.
*   **Infrastructure**: Design Tokens abstracted from Figma variables into the codebase.

## Typography System
*   **Sans-Serif**: ITC Avant Garde Gothic (Medium/Bold for headlines and brand identity).
*   **Serif**: Charter/Georgia (for dense body copy and long-form narrative).
*   **Governance**: All H1 and H5 elements must follow the established system weight (500).

## UI Methodology
*   **Atomic Design**: Components categorized as Molecules or Organisms inside Storybook.
*   **Iconography**: Lucide React.
*   **Deployment**: Vercel-aligned pipelines for interactive validation.
