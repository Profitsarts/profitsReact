# Vibras — 10 s explainer · storyboard

1920×1080 · 60 fps · 600 frames · every frame drawn by one `render(t)` on a 2D canvas.

## Synthesis of the 5 references → SHYLENCE / Vibras

| Reference | What it gives | How it lands in the brand |
|---|---|---|
| 13.29.41 — constructivist blocks (red square, circle, jittering black squares) | Overlapping translucent blocks, stepped jitter | Timeline blocks on the rail overlap in translucent graphite; stepped 12 fps "boil" on hand-drawn marks |
| 13.33.25 — kinetic floral poster | Type that slides through masks and wraps | Every caption line enters/leaves through its own mask, staggered |
| 03.14.03 — 1-bit dither swoosh | Three-tone ordered dither on a visible dot grid | The headphone is never a picture: it is an 8×8 Bayer dither on a 5 px dot grid (black / graphite / light) |
| 03.14.36 — node sequencer on grainy dark | Rail, diamonds, playhead, scratched dark texture | Bottom sequencer rail maps the 10 s; background has brushed-metal diagonal streaks (bead-blasted aluminium) |
| 03.18.22 — soft-square sine + glowing pills | Thin wave, sliding lit pills, one bloomed | The audio signal: thin soft-square sine, one bloomed **orange** pill |

Brand rules kept: stage `#000`, surfaces `#0a0a0a / #121212`, hairlines `rgba(255,255,255,.08/.20)`, ink `#ededed`, graphite `#8a8a8a → #4a4a4a` (SHYLENCE gradient), **one** accent `#ff5722` (the ANC toggle colour — used only for the toggle, the playhead, active callouts and the signal pill). Type: Space Grotesk (light display), JetBrains Mono (telemetry). Copy from the production page.

Hand-made texture: 24 fps film grain (overlay + screen), 12 fps gate weave (±0.6 px), dust specks and a stray hair at 12 fps, wobbling hand-drawn brackets and arrows, dither thresholds that boil at 12 fps, brushed streaks, vignette.
